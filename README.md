# 个人信息管家

记资料、管待办、排课表、把群通知变成日程。一个 HTML 文件，双击就能用。

**怎么用**：把仓库里的 `信息管家.html` 下载下来，用 Chrome / Edge 打开，不需要安装任何东西、不需要联网。
数据全部存在浏览器本地（`localStorage`），不上传、没有账号、没有服务端。

## 换台电脑怎么用

1. 把 `信息管家.html` 拷过去，用 Chrome / Edge 打开（数据存在浏览器本地，不上传）。
2. 老电脑上：设置页 → 导出备份，会下载一个 JSON。
3. 新电脑上：设置页 → 导入备份，选那个 JSON，资料、待办、课表全过来。

模型配置（接口地址、Key）**不在备份里**，换电脑要在设置页重新填一次。

## 三种用法，从简到繁

- **离线模式**：什么都不填也能用。分类、摘要、检索、问答走本地规则引擎，一分钱不花。
- **智能模式**：设置页填一个 OpenAI 兼容的接口（地址 + Key + 模型名），分类和问答交给大模型，按 token 计费。

## 接入 DeepSeek（推荐）

设置页「服务商」选 DeepSeek，三栏都是现成的，只需要贴 Key：

| 栏 | 值 |
|---|---|
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型名 | `deepseek-flash` |
| API Key | 在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 建一个 |

点「测试连接」能回一句「可用，回复：OK」就说明通了。

费用按 token 计。这个应用每次调用的量很小：一条资料的分类加摘要几百 token，
一次智能整理一两千，正常用一个月在几块钱量级。填了 Key 之后设置页会写「已保存到本机 · 时间」，
Key 只存在这台机器的浏览器里，不进备份、不上传。

想换别家也行：DeepSeek、Kimi、硅基流动、通义都有预设，「自定义」可以填任意 OpenAI 兼容接口。

### 报「连不上模型接口」是怎么回事

多一半是跨域，不是网络。页面是 `file://` 打开的，Origin 是 `null`；浏览器在发
POST + Authorization 之前先发 OPTIONS 预检，服务商不回跨域头就直接拦住，
`fetch` 抛错，看起来像断网。

实测（2026-10）：DeepSeek、通义 DashScope、硅基流动、Kimi、火山方舟都会回跨域头；
**智谱 open.bigmodel.cn 不回**，所以它的预设已经去掉了——用不了，别浪费时间。

## 课表导入

日历页 → 导入课表，三种输入都吃：

- 手打或粘贴：`周一 第1-2节 高等数学 教三201 张老师 1-16周`
- 教务系统表格：整块复制进来，Tab / 逗号分隔都认
- 文本文件：点「选择文件」读 .txt / .csv

解析结果一律先列成表格让人核对，不会直接写进日历。两个容易踩的坑：

- **开学日**：所有周次都是相对「第一周的周一」算的，填错整学期平移。文本里写 `# 第一周 2026-09-07` 会自动带入。
- **作息时间**：课表只写第几节，几点上课靠作息表换算。导入弹窗里「调整作息时间」有三套预设（通用 / 晚课 18:30 起 / 只有白天），也可以自己改。

## 智能整理

资料库页右上角「智能整理」：翻一遍全部资料，给出四类可以照做的建议——

| 类别 | 挑出来的东西 | 照做之后 |
| --- | --- | --- |
| 分类调整 | 还挂着「未分类 / 文件」这类占位分类的 | 改成建议的分类 |
| 补一句摘要 | 存了内容但没摘要的 | 补上一句话摘要 |
| 重复内容 | 同一件事记了两遍的 | 冗余那条归到「待归档」，保留信息全的那条 |
| 建议归档 | 超过 90 天没动、也没有未完成待办的 | 归到「待归档」 |

建议默认全选，不需要的取消勾选；**只改分类和摘要，不删任何一条**。
接了模型交给模型判（DeepSeek 填 `deepseek-flash` 即可），没接就走本地规则，
弹窗顶部会写清楚这次是谁判的。没接模型时弹窗里可以直接粘 DeepSeek 的 Key 接入，Key 只存在本机浏览器里。

## 导入本地文件 / 关联文件夹

资料库页右上角两个入口：

- **关联文件夹**：Edge / Chrome 桌面版支持，授权一次就记住，之后点「重新扫描」刷新清单，新文件会自己冒出来。
- **导入文件**：直接挑几个文件。所有浏览器都能用，但不会记住位置。

能读正文的是纯文本一类：txt / md / csv / json / 代码 / 网页（自动去标签）；中文 GBK 编码自动识别。
docx / xlsx / pdf 这类需要专门解码器的格式不硬读，只登记文件名和位置，清单里会标「无正文」。
同一个文件按「路径 + 大小」去重，重复导入会跳过。

浏览器限制说明白：只有你自己选中的目录会被读取，应用不会在后台扫磁盘；双击打开的本地文件在部分浏览器里拿不到「记住文件夹」的权限，这时候改用「选择文件」即可。

## 一键安排（通知 → 日程）

日历页右上角「一键安排」：把群通知整段粘进去，或从本机助手读取，解析出时间、地点、事项，按你在设置页填的身份（班级 / 职务 / 关注词）判断哪条和你有关；拿不准的逐条问「参加 / 待定 / 不去」。

**收集范围可调**：弹窗里选「最近 1~7 天」，设置页的「本机助手」里也能改，两边同步。默认只看今天。

- 往前看时会按**每条消息自己那天**算「明天」「本周五」。前天的通知里说「明天」，算的是昨天，不会被当成明天的日程。
- 微信消息流里没有绝对日期，只有「星期三 17:22」「昨天 12:15」「08:55」这类**分割条**。现在拿这些条子校准后面的消息属于哪天，
  条子本身不进结果（以前它被当成一条「17:22」的消息，于是两天前说「明天摆摊」的活动会被排到未来）。
- 已经过去的通知会标「已过期」并压暗，默认决策是「不去」，不会污染日历。
- 范围越大，微信要往回翻的消息越多，读取会慢一点（上限 400 条消息）。

收集范围最多往回一周。日期早于今天的事（按天判，今天下午的会不算过期）在预览里默认**隐藏**（顶部有个「隐藏已过期（N 条）」的勾，
去掉就能补记），也不会进入「逐条问你」的队列，更不会写进日历。

## 飞书：直读群消息（推荐）

飞书界面是 Chromium 自绘的，窗口里读不到聊天文本，所以老办法只能「弹到前台 + 你复制 + 读剪贴板」。现在多了直读这条路：走飞书开放平台接口，拿到的是一条条结构化消息——发送人、精确到分钟的时间、消息 ID，不需要窗口在前台。

**第一次要授权一次**（约 1 分钟，之后自动续期）：

```bash
pip install lark-oapi                  # 只需要一次
python bridge/feishu_sdk.py register   # 建一个自建应用，扫码确认
python bridge/feishu_sdk.py login      # 用户授权，打开链接确认
python bridge/feishu_sdk.py chats      # 看看能读到哪些群
```

也可以在设置页 → 本机助手 → 飞书里点「扫码授权」，链接会直接显示出来。

- 建应用和授权都是扫码确认，**不用去开发者后台手动点选权限**；申请的权限只有「读群消息」和「读群信息」。
- 凭据存在 `bridge/feishu_auth.json`（含 app secret 和 token），**不要提交到任何仓库**，换电脑也别直接拷。
- 读哪些群在设置页填（逗号分隔），留空就完全不读飞书。
- 随时可以退回老办法：设置页把「读取方式」切回「弹到前台 + 复制」，不用改代码。

## 日常怎么开（一条路，别记别的）

双击 **`启动信息管家.bat`**。它做三件事：

1. 探一下 `127.0.0.1:8787`——本机助手刚才就在跑，直接跳到第 3 步，不重复起；
2. 不在跑就挑一个能 `import wxauto4` 的解释器（`py -3.13` → `3.12` → `3.11` → `python` 依次试），
   最小化起一个窗口，日志写 `bridge/bridge.log`，最多等 20 秒；
3. 打开 `信息管家.html`。

用完双击 **`停止本机助手.bat`**（走 `/quit`，端口干净释放，不用任务管理器杀）。
一直挂着也没关系，它只监听本机回环，不联外网。

出问题就双击 **`bridge\启动本机助手.bat`**：前台运行，日志直接打在窗口里，看得到 Python 报什么。

小脚本都是 **GBK 编码 + CRLF 换行**，别用 UTF-8 编辑器另存——cmd 会把中文字节当命令解析，
表现是「'em' 不是内部或外部命令」这类莫名其妙的错。

## 本机助手（可选，只在这台机子上）

`bridge/notice_bridge.py` 会从微信白名单群读消息、从剪贴板收飞书的总结，在 `127.0.0.1:8787` 提供服务。**不跑它，上面所有功能照常可用**，只是通知要靠手粘。

```bash
pip install wxauto4 pywin32 lark-oapi
py -3.13 bridge/notice_bridge.py
```

**关于解释器**：微信那条路靠 `wxauto4` 做界面自动化，它只在装了它的那个 Python 里能用。
如果机器上有好几个 Python，用错一个就会看到「没有可用的 wxauto4」——报错里会带上当前解释器的完整路径，
换 `py -3.13` 启动即可（`启动信息管家.bat` 已经自动挑，不用自己判断）。
设置页的「本机助手」卡片会直接显示**微信通道可用/不可用**和解释器路径，不用猜。
`wxauto4` 需要**微信 4.x**（进程名 `Weixin.exe`），3.9 那代用不了。

微信要读哪些群、往回读几天，都在设置页的「本机助手」卡片里填（点「从微信读取会话名」可以直接选），不用手改 config.json。配置里对应的是 `wechat.sessions` 与 `wechat.days`（1~7）。飞书是自绘界面、抓不到窗口文本，所以走「弹到前台 → 你复制 → 脚本读剪贴板」；剪贴板只有当下这一份，和天数无关。

第一次跑它会自己生成 `bridge/config.json`。想直接改文件的话，从 `bridge/config.example.json` 复制一份再填——
**`config.json` 和 `feishu_auth.json` 都在 `.gitignore` 里**，因为前者存着你的群名、后者存着飞书的 app secret 和 access token，都不该进仓库。

## 隐私

- 资料、待办、课表、日程都在浏览器 `localStorage`（键 `infobutler.local.v1`），没有服务端，也没有账号体系。
- 模型配置（接口地址、Key）单独存在 `infobutler.llm.v1`，**不会随「导出备份」走**，换电脑要重填。
- 只有你主动点「智能整理 / 问答 / 一键安排」且配了模型时，相关文本才会发给你指定的那家接口。
- 本机助手只监听 `127.0.0.1:8787`，不对外；微信那条路靠界面自动化，不联网。

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产出 dist/index.html（单文件）
npm run lint
```

发版时把 `dist/index.html` 复制成 `信息管家.html` 即可。
